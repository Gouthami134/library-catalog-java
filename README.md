# Library Catalog 

An original command-line learning project for adding books to an in-memory catalog, listing entries, and searching titles or authors. Entries are cleared when the program exits.

## Requirements
- Java Development Kit (JDK) 17 or later
- A terminal

## Run
```sh
javac LibraryCatalog.java
java LibraryCatalog
```

## Concepts
Java classes, lists, streams, case-insensitive search, menu loops, and input validation.

## Scope
A small learning exercise without checkout, accounts, or persistent storage.
